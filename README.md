# Order Mession

Order Mession is a custom PHP MVC web application for managing government vehicle licenses and authorizations.

## Features

- User login and logout
- Session-based authentication
- Protected pages
- Add licenses
- Edit licenses
- View licenses
- Delete licenses
- Search licenses
- Printable license documents
- A5 print layout

## Technology

- PHP
- Custom MVC Architecture
- PDO
- MySQL
- HTML
- SCSS / CSS
- JavaScript
- Apache / XAMPP
